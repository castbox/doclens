# 详情页 DeepSeek 文档聊天交付记录

## 需求与实现

- 详情页右上角在“加入星标”左侧新增 44px Chat 图标按钮。
- 点击打开全屏聊天，先恢复该详情页的服务端历史；仅空历史自动用中文简洁解读当前文档。回答铺满内容区，问题采用右侧气泡。
- 支持 Mermaid 图表、Markdown 表格、连续追问、流式输出、停止、重试、Enter 发送、Shift + Enter 换行及中文输入法。每轮优先用一张简洁图或紧凑表格说明，只保留核心关系及必要文字。
- 聊天中的 Mermaid 仅显示图表，移除外框、背景及标题栏；44×44px 放大按钮浮在图表右上角。放大后按自然尺寸显示，可水平平移阅读。
- 消息区独立滚动，输入区固定在底部；用户上翻时不抢滚动，支持回到底部、Escape 关闭和移动端安全区。
- 每轮由服务端安全读取当前详情全文，固定加入系统参考上下文；浏览器只提交路径及 summary/send/retry 动作，不可替换正文或服务端历史。文档始终作为参考，不被聊天上下文预算裁剪。
- SQLite 按真实文档根目录和规范化相对路径保存全部聊天记录。默认读取最新页，并可加载更早记录；模型只选择近期上下文，历史保存没有 20 轮上限。
- SQLite generation lease 和令牌校验阻止同一文档并发生成；每个增量先落库再发送。停止、错误或中断保留部分输出；重试追加新尝试，保留旧回答并关联原问题。
- 密钥仅保存在 Git 忽略的本地 `.env`，服务端读取；默认官方 DeepSeek `deepseek-flash`。用户提供的密钥未写入源码、文档或测试记录。
- PDF 和二进制文件暂不支持文本聊天，入口禁用并说明原因。超限文档或会话明确提示，不静默截断。

需求来源：[PRD FR-14/FR-15](../../../prd/doclens_prd.md)。配置及冒烟：[README](../../../../README.md)。接口依据：[DeepSeek 官方首次调用文档](https://api-docs.deepseek.com/zh-cn/)。

## 12 个 Parallel Specialists 的实际分工

| 专项代理 | 独立责任 / 文件 |
| --- | --- |
| `detail_entry` | 聊天入口与懒加载；数据库 schema、增量迁移、历史仓库与回归 |
| `prd_docs` | PRD SSOT 与 README |
| `chat_domain` | 请求动作、持久历史类型、近期上下文选择、图表优先提示词及纯函数测试 |
| `deepseek_service` | 服务端配置、安全全文上下文、上游流式调用与取消 |
| `chat_api_route` | `app/api/chat/route.ts` 的来源、请求体与错误边界 |
| `stream_client` | SSE 分块解析、浏览器请求及流式协议测试 |
| `chat_session` | 会话 Hook、StrictMode、取消、重试及生命周期测试 |
| `fullscreen_dialog` | 全屏布局、滚动、错误反馈与响应式 |
| `message_markdown` | 助手 Markdown 安全渲染及用户气泡 |
| `chat_composer` | 输入、IME、焦点与发送 / 停止交互 |
| `api_security_tests` | API 与服务安全回归，全部 mock 上游调用 |
| `ux_review` | 独立静态 UX / 可访问性审查与视觉复核 |

父代理统一冻结组件合同、读取产物并集成；执行全量测试、生产构建、本机浏览器验收、凭证与 Git 收尾。专项之间不提交、不覆盖其它专项的文件。

## 边界、影响与回滚

- 仅新增文档聊天及其 API；星标、复制路径、导出、搜索和审阅单既有接口保持。
- 文档字符 / 字节与问题长度上限详见 README；超限需缩小文档或精简问题。更早对话仍完整保存，本轮模型请求只选取预算内的近期对话，并始终附上当前文档全文。
- 首次空历史概述、发送问题或手动重试会将当前文档全文和对应上下文发送给官方 DeepSeek；恢复与分页只读取 SQLite。关闭窗口取消本次请求，已保存内容保留。
- 新增两张聊天表和索引；源文档、审阅单、已读和星标既有数据保持。现有 `.env` 的默认文档目录不存在，构建中 PR 文件监听提示 ENOENT 并回退按请求同步；构建成功。验收使用独立临时根目录，不修改原配置。
- 工作区原有 `main` 领先远端的两个提交和未跟踪 `test.zip` 保留。
- 回滚可 revert 本次 feature commit；新增聊天表保留，不自动删除历史。旧代码不使用新增表；本地 `.env` 中新增的 DeepSeek 配置按需自行保留或移除。
